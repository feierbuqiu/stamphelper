# Support

## Usage and postal-data questions

Search existing [issues](https://github.com/feierbuqiu/stamphelper/issues) before opening a new one. Include the product, origin, destination, transport mode, contents type, weight, selected extras, expected result, observed result, and the source/date supporting any proposed rate correction.

Do not include addresses, tracking numbers, telephone numbers, identity documents, receipts containing personal details, browser-storage exports, credentials, or private postal records.

## Bugs and feature requests

Use the repository's issue forms. A minimal reproduction, browser and operating-system versions, and an anonymized screenshot are useful. Remove personal information before uploading screenshots.

## Security issues

Follow [SECURITY.md](SECURITY.md) and use private vulnerability reporting. Public issues are not an appropriate place for exploit details.

## Operational disclaimer

This independent project cannot confirm whether a particular counter will accept a mailing. China Post's live acceptance system and staff remain authoritative for actual service availability and final charges.
